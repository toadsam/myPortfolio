### ⚠️ 본인 코드가 저장소에 없다 — 가장 큰 문제

유일한 `.cs` 파일이 **에셋스토어 워터 셰이더**다. 역할이 "프로그래밍 담당"인데
**본인이 짠 스크립트가 한 줄도 안 올라가 있다.**

가능한 원인:

1. `.gitignore` 에 `Scripts/` 나 `*.cs` 가 걸렸다
2. 다른 브랜치·다른 팀원 저장소에 있다
3. 파일 트리 응답이 4,000개에서 잘려서 안 잡혔다

**"프로그래밍 담당"이라고 쓰고 저장소를 열었는데 에셋만 있으면 역효과가 난다.**
확인이 최우선이다.

또 하나 — 저장소가 `DarkLab` 인데 최상위 폴더는 `Threshold` 다.
**프로젝트 이름이 바뀐 흔적**으로 보인다. README에 설명이 없으면 심사자가 헷갈린다.

## ✋ 직접 만들 것

### 1. 저장소 스크립트 확인 ⭐⭐⭐ — 최우선

위 ⚠️ 참고. 이게 해결돼야 나머지가 의미를 갖는다.

### 2. 인게임 화면 ⭐⭐⭐ — 3장, Unity 에디터로 5분

**이력서에서 가장 빨리 채울 수 있는 빈 슬롯이다.** 에디터 열고 Play 누르면 끝.

| 슬롯        | 필요한 화면                               |
| ----------- | ----------------------------------------- |
| 대표 (16:9) | 가장 분위기 있는 한 장                    |
| 갤러리 ①    | 1인칭 탐색                                |
| 갤러리 ②    | URP 라이팅·분위기 연출 ← 공포 게임의 핵심 |
| 갤러리 ③    | 상호작용 구간                             |

**어두운 게임이라 사이트 톤(밤하늘 남색)과 잘 맞는다.** 밝은 웹 캡처보다 어울린다.

### 3. 플레이 영상 ⭐⭐

다른 게임 4개는 전부 영상이 있는데 DarkLab만 없다. **에디터에서 3분 녹화**하면
유튜브에 올려 링크를 걸 수 있다. 공포 게임은 정지 화면보다 영상이 훨씬 잘 산다.

### 4. 팀 협업 흔적 ⭐⭐

3인 팀인데 증거가 없다. 역할 분담(프로그래밍/아트/기획?), 회의록, 일정.

### 5. 학기 산출물 ⭐

2024-1 학기 팀 프로젝트다. 발표 자료·기획서가 있으면 문제 정의와 화면 설계가
정리돼 있을 가능성이 높다.
