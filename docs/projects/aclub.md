# aClub

> **증명하는 것**: 실사용자 3,500명이 쓴 서비스를, **팀원으로 시작해 이듬해
> 프로젝트장으로 다시 만든** 경험. 이력서에서 유일하게 "맡겨보니 잘해서 더 큰 걸
> 맡겼다"가 두 번 반복되는 프로젝트다.

- 2025 `DBProject-24-2/DB_Project_FE` — 프론트 3인 중 1인
- 2026 `aClub2026/FE` — **프로젝트장 · 프론트 리드**
- 라이브 `aclub.co.kr` (200 OK)

---

## 저장소에서 확인한 사실

### 2025 → 2026 개편의 실체는 **JS → TS 전면 전환**이다

|           | 2025 (팀원)  | 2026 (프로젝트장)                                                           |
| --------- | ------------ | --------------------------------------------------------------------------- |
| 소스      | **JSX 68개** | **TSX 58 + TS 22**                                                          |
| 타입      | 없음         | TypeScript                                                                  |
| 폴더 구조 | `src` 평면   | `components 41 · pages 15 · Hooks 7 · api 5 · utils 4 · types 3 · stores 1` |
| 아이콘    | jpg/png 21장 | **SVG 27개**                                                                |
| 배포      | —            | `CNAME` (커스텀 도메인)                                                     |

**이게 프로젝트장으로서 내린 기술 결정의 증거다.** 지금 사이트에는 "2026 프로젝트
총괄"이라는 글자만 있고, 무엇을 바꿨는지가 없다. 위 표가 그 답이다.

`Hooks` · `api` · `stores` · `types` 폴더가 2026에만 있다는 것은 **관심사를 분리하는
구조로 재설계했다**는 뜻이다.

## ✋ 직접 만들 것

### 1. Before / After 화면 ⭐⭐⭐ — 이 프로젝트에서 가장 강력

**2025 버전과 2026 버전의 같은 화면**을 나란히. 이게 있으면 "프로젝트장을 맡아
개편했다"가 주장에서 사실로 바뀐다.

찾을 곳:

- 2025 저장소(`DBProject-24-2/DB_Project_FE`)를 로컬에서 띄워 캡처
- `src/` 에 jpg 15장·png 9장이 있으니 그중 화면 캡처가 있을 수 있다
- 발표 자료·중간보고서
- **에브리타임 홍보 글에 올린 옛 화면** (PDF 20쪽에 그 캡처가 있다)

권장 대상: **메인 탐색 화면**, **동아리 상세**, **모집 신청 폼**

### 2. 실제 서비스 화면 ⭐⭐

지금 갤러리 3장 중 2장이 GA4 대시보드와 에타 게시글이다. **정작 서비스 화면이
1장뿐**이다. 필요한 것:

- 카테고리별 탐색 (핵심 개선 포인트)
- 동아리 상세 → 신청 흐름
- 마이페이지 / 로그인 상태

### 3. 유저 플로우 ⭐⭐

**툴**: Figma · Whimsical
`에브리타임/카톡 유입 → 랜딩 → 카테고리 탐색 → 상세 → 신청` 동선을 실제 캡처로
이어 붙인 그림. **동선 설계가 핵심 기여인 프로젝트라 특히 잘 맞는다.**
PDF 15쪽의 "사용자 유입 경로 최적화 / 정보 탐색 효율 개선 / 참여 전환율 향상"이
여기서 증명된다.

### 4. 팀 협업 흔적 ⭐⭐ — 프로젝트장이면 더 중요하다

- 2026 저장소의 **PR 리뷰 코멘트** (내가 남긴 리뷰가 특히 좋다 — 리드 역할의 증거)
- 이슈 · 스프린트 보드 · 역할 분담표
- 회의록

### 5. GA4 근거 화면 (선택) ⭐

지표 4개의 출처를 이미 라벨로 적어 뒀으니 필수는 아니다. 넣는다면 **1장이면
충분하다** — 계정명·이메일은 가릴 것.
