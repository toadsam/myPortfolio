## ⚠️ 가장 먼저 — GitHub 링크가 죽었다

```
https://github.com/KimEoJin24/TSEROF  →  404 Not Found
```

이력서 카드와 상세 페이지 양쪽에 이 링크가 걸려 있다. **심사자가 누르면 404를 본다.**
이력서 전체 URL 25개 중 유일하게 죽은 링크다.

원인은 셋 중 하나다.

1. 저장소가 **private** 으로 바뀌었다 → 팀장께 공개 요청
2. **삭제**됐다 → 본인 포크나 로컬 사본이 있는지 확인
3. **이름이 바뀌었다** → 새 주소 확인

**어느 쪽이든 지금 상태로 두면 안 된다.** 살릴 수 없으면 링크를 빼야 한다.
Steam 링크와 플레이 영상이 있으니 GitHub 없이도 증명은 된다.

> 참고: API·웹 페이지 둘 다 404다. 접근 권한 문제가 아니라 존재하지 않는다.

## ✋ 직접 만들 것

### 1. Steam 스토어 페이지 캡처 ⭐⭐⭐

**출시했다는 가장 직접적인 증거.** 스토어 페이지 상단(제목·가격·태그·스크린샷)
1장. 리뷰가 있으면 그것도.

### 2. 실제 인게임 플레이 화면 ⭐⭐⭐

지금 대표 이미지가 **AI 생성 타이틀 일러스트**다. 게임 실력을 보여주지 못한다.
필요한 것:

- 실제 플레이 화면 (장애물·기믹이 보이는 구간)
- **본인이 만든 레벨** ← 역할이 레벨 디자인이라 이게 핵심이다
- 기믹 작동 장면

플레이 영상(`1Lm-lpVsmq8`)에서 뽑으면 5분이면 된다.

### 3. 레벨 디자인 자료 ⭐⭐⭐ — 본인 역할의 직접 증거

- **레벨 설계도 / 종이 스케치**
- 그레이박스 프로토타입 → 최종 비교
- 기믹 배치 의도 메모

**"레벨 디자인 담당"이라고 쓰여 있는데 레벨을 보여주는 자료가 없다.**
이 프로젝트에서 가장 아쉬운 부분이다.

### 4. 팀 협업 흔적 ⭐⭐

5인 팀 부팀장인데 증거가 없다. 역할 분담표, 회의록, 일정표, 태스크 보드.
**부팀장이면 조율한 흔적이 있어야 그 직함이 산다.**

### 5. 출시 과정 자료 ⭐⭐

Steam 심사 통과, 빌드 업로드, 스토어 페이지 준비 — **출시를 해 본 사람만 아는
과정**이다. 그 흔적(체크리스트·심사 메일 등)이 남아 있으면 강력하다.

### 6. 유저테스트 원자료 ⭐

슬라이드는 있는데 원자료(설문 응답, 테스터 수, 진행 방식)가 있으면 더 좋다.
**몇 명에게 테스트했는지**가 지금 안 나온다.

## ⚠️ 확인·수정 필요

- **GitHub 404** (위 참고) — 최우선
- 대표 이미지가 AI 생성 일러스트다. **실제 게임 화면으로 교체 권장.**
- 카드 상태가 `출시` 로 되어 있고 금색 배지가 붙는다. 상세 상단에는 상태 표시가
  없는데(`demo.live` 기준), **Steam URL을 `live` 로 넣어 "출시됨" 배지를 띄울지**
  결정 필요.

| 질문                            | 답할 재료                                                                                                                              |

| 부팀장으로 뭘 했나요?           | 레벨 디자인 · 장애물/기믹 구현 · 기획. ← 조율 사례가 하나 더 있으면 좋다                                                               |

| 판매량은요?                     | ← 있으면 강력. 없으면 "출시가 목표였다"고 사실대로                                                                                     |
