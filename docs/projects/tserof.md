## ✋ 직접 만들 것

### 1. Steam 스토어 페이지 캡처 ⭐⭐⭐

**출시했다는 가장 직접적인 증거.** 스토어 페이지 상단(제목·가격·태그·스크린샷)
1장. 리뷰가 있으면 그것도.

### 2. 실제 인게임 플레이 화면 ⭐⭐⭐

지금 대표 이미지가 **AI 생성 타이틀 일러스트**다. 게임 실력을 보여주지 못한다.
필요한 것:

- 실제 플레이 화면 (장애물·기믹이 보이는 구간)
- **본인이 만든 레벨** ← 역할이 레벨 디자인이라 이게 핵심이다
- 기믹 작동 장면

플레이 영상(`1Lm-lpVsmq8`)에서 뽑으면 5분이면 된다.

### 3. 레벨 디자인 자료 ⭐⭐⭐ — 본인 역할의 직접 증거

- **레벨 설계도 / 종이 스케치**
- 그레이박스 프로토타입 → 최종 비교
- 기믹 배치 의도 메모

**"레벨 디자인 담당"이라고 쓰여 있는데 레벨을 보여주는 자료가 없다.**
이 프로젝트에서 가장 아쉬운 부분이다.

### 4. 팀 협업 흔적 ⭐⭐

5인 팀 부팀장인데 증거가 없다. 역할 분담표, 회의록, 일정표, 태스크 보드.
**부팀장이면 조율한 흔적이 있어야 그 직함이 산다.**

### 5. 출시 과정 자료 ⭐⭐

Steam 심사 통과, 빌드 업로드, 스토어 페이지 준비 — **출시를 해 본 사람만 아는
과정**이다. 그 흔적(체크리스트·심사 메일 등)이 남아 있으면 강력하다.

### 6. 유저테스트 원자료 ⭐

슬라이드는 있는데 원자료(설문 응답, 테스터 수, 진행 방식)가 있으면 더 좋다.
**몇 명에게 테스트했는지**가 지금 안 나온다.

## 상세 페이지 이야기 배치 (2026-11-14 적용)

`/resume/tserof` 가 이 배치입니다. 시안 주소는 적용하면서 지웠습니다. 개정분은 `src/components/ui/project-viewers/richContent/tserofStory.ts` 에 있습니다.

- 순서는 문제, 맡은 일, 표(여섯 줄), 결과와 남은 것입니다. 화면 절은 두지 않았습니다.
- 표는 11월의 세 줄(씬 통합, 퍼즐, 큐브)과 12월의 세 줄(고드름 판정, 2단 점프 피드백, 공통 인터페이스)입니다.

로컬 클론(`문서/GitHub/TSEROF`, 전 브랜치 1,204 커밋)으로 다시 확인한 것:

- 퍼즐의 실제 규칙을 찾았습니다. 칸은 빈칸·얼음·물 세 값이고, 가로줄과 세로줄 버튼 여섯 개가 그 줄 세 칸을 한 단계씩 넘깁니다. 리셋 버튼은 전부 빈칸으로 만듭니다. 정답 패턴 다섯 개는 25초마다 바뀌고 그때 판은 전부 물로 돌아갑니다. 예전 원고는 "패턴 값은 예시"라고 적고 칸을 직접 누르는 판을 실었습니다. 시안의 퍼즐은 실제 패턴 다섯 개와 실제 규칙입니다.
- 본인 커밋은 2023-10-25 부터 12-13 까지 216개입니다(10월 28, 11월 144, 12월 44). 저장소 첫 커밋 10-23 은 팀원 것입니다.
- 유저 테스트의 「고드름 판정」 조치는 본인 커밋입니다(2023-12-04, FallingObject.cs). 「통나무 리스폰」은 스테이지 1 담당 팀원의 기믹이고 「카메라 Y축」은 누가 했는지 확인하지 못해 적지 않았습니다.
- 낙하물 그림의 「만들고 부수던 이전 코드」는 그 파일의 커밋 이력에 없습니다. 확인되는 것은 2023-12-07 의 대기 시간 캐싱뿐입니다. 그림 설명을 그렇게 고쳤습니다.
- README 기여자 표에 본인 이름으로 적힌 스크립트는 13개이고, 퍼즐 폴더의 커밋 26개 중 20개가 본인 것입니다.
