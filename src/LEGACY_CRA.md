# Legacy CRA Source

This repository still contains the previous Create React App portfolio source, including `src/App.js`, `src/index.js`, `src/containers`, and older `.js/.jsx` components.

The active application is the Next.js app at `src/app/page.tsx`.

The CRA files are kept as reference material for older portfolio sections and assets. They are not imported by the Next.js entrypoint and are not included in the TypeScript build.
