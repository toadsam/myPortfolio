# 02. MyStock-Desk — 「트레이딩 데스크」

> 거래 기록 기반 포트폴리오 분석 + AI 체크리스트 · React / TS / Spring Boot / Recharts / MySQL
> 테마: `primary #38bdf8` / `secondary #0ea5e9` / `bg #040d18` / `accent #7dd3fc`

---

## 0. 한 줄 컨셉

**"모니터 여섯 대짜리 트레이딩 데스크에 앉는다."**

MyWave가 부드럽고 느리다면, 이건 **빽빽하고 빠르다.** 정보 밀도로 압도하는 화면.
프로젝트 이름에 이미 `-Desk`가 붙어 있다. 그 단어를 화면으로 만든다.

핵심 차별점: 이 프로젝트는 **AI가 추천하지 않고 점검한다**는 게 설계 철학이다.
그래서 화면에서도 AI 영역은 "예측 패널"이 아니라 **체크리스트가 하나씩 체크되는 감사(audit) 패널**로 보여준다.

## 1. 아트 디렉션

| 항목 | 값 |
|---|---|
| 배경 | `#040d18` + 미세 격자(grid) `rgba(56,189,248,0.045)` 24px — 관제실 바닥 |
| 주색 | `#38bdf8` 시안 |
| 상승 | `#22c55e` / 하락 `#ef4444` — **한국 증권 관습(빨강=상승) 쓰지 말 것.** 글로벌 관습(녹색=상승)으로 통일하고 범례 명시 |
| 타이포 | **전면 `font-mono`.** 본문까지 mono. 이 프로젝트만의 규칙 (터미널 컨셉) |
| 숫자 | `tabular-nums` 필수. 금액 폭이 흔들리면 안 됨 |
| 모서리 | `rounded-md` — 각지게. MyWave와 정반대 |
| 보더 | 1px `rgba(56,189,248,0.22)` 실선. 패널 간 갭은 **6px로 좁게** (밀도) |
| 모션 톤 | **짧고 딱딱.** duration 0.15~0.3s, `ease-out`. 숫자는 페이드가 아니라 **틱(tick) 교체** |
| 사운드 | variant `data`. 짧은 클릭 틱 + 낮은 험(hum). 체크리스트 체크될 때마다 `틱` |

### 이 프로젝트만의 장치
- **상단 티커 테이프**: 화면 최상단에 높이 28px 밴드, 종목 코드/등락률이 오른쪽→왼쪽으로 무한 흐름. **모든 섹션에서 상시 표시.**
- **패널 헤더 규격**: 모든 패널 좌상단에 `▸ PANEL_NAME` + 우상단에 `LIVE` 또는 `MOCK` 뱃지

## 2. 진입 연출 (0 → 2.2초)

**부팅 시퀀스.** 패널이 한 번에 안 뜨고 순차로 켜진다.

```
0.0s  검은 화면 + 격자만 희미하게
0.2s  티커 테이프 밴드가 위에서 슬라이드 인, 즉시 흐르기 시작
0.4s  좌상단 패널 켜짐 (opacity 0→1, 0.15s, 틱 사운드)
0.6s  우상단 패널
0.8s  좌하단 / 1.0s 우하단  ← 총 4개가 0.2s 간격으로 다다닥
1.3s  중앙에 타이틀 오버레이 등장
      MyStock-Desk
      TRADE LOG → PORTFOLIO → AI AUDIT
1.9s  오버레이가 위로 흡수되며 사라짐
2.2s  본문 스크롤 활성화
```

- 사운드 ON이면 부팅 틱 4회 + 마지막에 낮은 `핑`
- **스킵**: 클릭/키/스크롤 → 1.9s 상태로 점프
- `reduced-motion` → 패널 전부 즉시 표시, 티커는 흐르지 않고 정지 표기

### SHEET 3 — 설계 결정

이 프로젝트의 가장 강한 카드는 **"AI에게 무엇을 시키지 않았는가"** 다. 그걸 전면에 낸다.

```
┌───────────────────────────────────────────────────────────────┐
│ ▸ DECISION 01 — AI의 역할을 좁혔다                            │
│                                                               │
│   ✗ 하지 않은 것              ✓ 한 것                         │
│   ─────────────              ─────────────                    │
│   "이 종목 사세요"            "특정 섹터에 62% 편중됐습니다"    │
│   "지금이 저점입니다"         "3건의 거래에 메모가 없습니다"    │
│   목표주가 예측               "현금 비중이 5% 미만입니다"       │
│                                                               │
│   [COPY-03] 아래                                              │
└───────────────────────────────────────────────────────────────┘
```

**[COPY-03]**
> 투자 추천을 하는 순간 이 서비스는 책임질 수 없는 말을 하게 된다.
> 그래서 AI를 **판단자가 아니라 감사자**로 두었다.
> 사용자가 이미 한 결정을, 사용자가 정한 기준으로 점검만 한다.
> 이 제약이 프롬프트도 응답 스키마도 훨씬 단순하게 만들었다.

기타 결정 (`DecisionTable` 재사용):

| 영역 | 선택 | 이유 | 대안 |
|---|---|---|---|
| 수익률 계산 | 서버(Spring Boot) | 계산 규칙이 한 곳에만 있어야 함 | 클라이언트 계산 — 화면마다 값이 달라질 위험 |
| 차트 | Recharts | 선언형, React 트리와 상태 공유 쉬움 | D3 직접 — 자유롭지만 이 규모엔 과함 |
| 외부 시세 API | mock fallback 필수 | API 죽어도 화면은 살아야 함 | 에러 화면 — 데모에서 최악 |
| AI 응답 | 고정 JSON 스키마 | 파싱 실패 = 화면 붕괴 방지 | 자유 텍스트 — 렌더 불가능 |

- **[CODE-01]** 거래 기록 → 보유 종목/수익률 계산 로직 · **14~20줄** · `PortfolioCalculator.java` 또는 해당 서비스
  포인트: 평균 매입가 계산 부분 하이라이트. **이 프로젝트에서 가장 도메인 밀도가 높은 코드.**
- **[CODE-02]** AI 체크리스트 응답 스키마 + 파싱 · **10~14줄**
  포인트: 스키마를 고정했다는 사실이 보이게. `response_format` / DTO 부분 하이라이트
- **[CODE-03]** 외부 API 실패 시 mock fallback · **8~12줄**
  포인트: `catch` 에서 화면이 죽지 않고 mock으로 넘어가는 흐름

## 4. 시그니처 인터랙션 — 「AI 감사 패널」

**[NEW]** `AiAuditPanel` (기존 `MyStockDemo.tsx` 를 이 컨셉으로 재작성)

SHEET 1 우하단 패널이 **뷰포트에 들어오면 스스로 감사를 실행**한다.

```
▸ AI AUDIT                                    [ 다시 실행 ↻ ]
─────────────────────────────────────────────────────────
  분석 중  ▓▓▓▓▓▓▓░░░░░░░  48%          ← 0.8s 진행바

  ✓ 섹터 편중         반도체 62%          ⚠ 주의
  ✓ 기록 누락         3건 메모 없음        ⚠ 주의
  ✓ 현금 비중         22%                 ✓ 양호
  ✓ 손절 기준         미설정               ⚠ 주의
  ✓ 거래 빈도         월 4회               ✓ 양호
─────────────────────────────────────────────────────────
  // 추천이 아니라 점검입니다. 매수·매도 의견을 내지 않습니다.
```

동작 명세:
1. 뷰포트 진입 → 진행바 0→100% (0.8s)
2. 진행 중 항목들은 `☐ ...분석중` 회색 상태
3. 진행바 완료 후 **항목이 0.18s 간격으로 순차 확정** — 체크마크가 찍히고, 결과값이 `DecodeText` 로 스크램블→확정
4. 각 항목 확정마다 짧은 `틱` 사운드
5. `⚠ 주의`는 앰버 `#fbbf24`, `✓ 양호`는 `#22c55e`
6. 하단 면책 문구는 **항상 고정**. 이게 이 프로젝트의 주장이다.
7. `↻ 다시 실행` 클릭 시 전체 시퀀스 재생 (관람객이 한 번 더 보고 싶어하는 지점)

성능: 타이머 기반이므로 언마운트 시 `clearTimeout` 전부 정리. 뷰포트 이탈 시 일시정지.
