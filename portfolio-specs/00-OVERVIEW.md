## 1. 이 폴더의 정체 — 코드가 아니라 **프롬프트 팩**입니다

이 폴더의 10개 문서는 **설계 문서가 아니라 Variant(디자인 AI)에 그대로 붙여넣는 프롬프트 묶음**입니다.
각 문서는 `PAGE 00` ~ `PAGE 10`, 총 11개의 ` ```text ` 코드블록을 갖고 있고,
**그 코드블록 하나가 곧 화면 한 장의 완성 프롬프트**입니다.

### 사용법

````
1. 문서를 연다 (예: 09-darklab.md)
2. "## PAGE 00" 아래의 ```text 코드블록을 통째로 복사한다
3. Variant에 붙여넣는다 → 화면 한 장이 나온다
4. PAGE 01, 02 … 10 을 같은 방식으로 반복한다
````

- **각 프롬프트는 완전히 자립적**입니다. 색상·폰트·무드·접근성 규칙이 매 페이지 반복 포함되어 있어
  앞 페이지를 안 봐도 됩니다. 한 장씩 따로 뽑아도 톤이 유지됩니다.
- `# A`(컨셉 브리프) · `# B`(토큰 표) · `# D`(구현 메모) 는 **읽기용**이지 프롬프트가 아닙니다.
  Variant에 넣지 마세요.
- 프롬프트 지시문은 **영어**, 화면에 나올 한국어 카피는 **`VERBATIM:` 뒤에 그대로** 적혀 있습니다.
  **번역 금지**가 프롬프트 안에 명시돼 있으니 그대로 두세요.

### 왜 갈아엎는가 (한 문단 요약)

현재 `shared.tsx` 의 `RichProject` 인터페이스 하나에 10개 프로젝트가 전부 끼워 맞춰져 있습니다.
`tldr → demo → meta → heroScreen → impact → features → problem → …` 순서가 **10개 모두 동일**해서,
지금은 색깔(`projectThemes.ts`)만 다르고 **화면 구조와 리듬은 전부 같습니다.**
이 프롬프트 팩은 그걸 **프로젝트 1개 = 전용 화면 11장**으로 바꾸기 위한 것입니다.

> 🔴 구버전 개요에 있던 `[CODE-nn]` / `[NUM-nn]` 태그 규약은 **폐기됐습니다.**
> 현재 각 문서는 `[IMG-nn]` · `[VIDEO-nn]` 두 개만 쓰고, 코드는 `D-6` 표로, 수치는
> **"지어내지 않고 못 잰 것을 명시"** 하는 방식으로 처리합니다 (§3 규칙 2 참고).

## 3. 전 문서 관통 규칙 (절대 어기지 말 것)

10개 문서 전부가 이 규칙 위에 서 있습니다. 프롬프트를 손으로 고칠 때도 이 선은 넘지 마세요.

1. **연출은 개발 내용의 운반 수단이다.** 멋있기만 한 연출 금지. 모든 페이지에 개발 실체 최소 1개.
2. **지어낸 수치·정황 0개.** 사용자 수·DAU·다운로드·ms 개선치 주장 금지.
   **날짜·시간·인물이 붙은 장면("리허설 날", "친구가 테스트해줬는데")도 금지.**
   대신 **"재보지 못한 것"** 카드. 실측값은 저장소에 있는 것만 (예: 08의 `playtest-output-*/`).
3. **한계 인정을 매 프로젝트 4곳 이상**에 배치
   (P03 포기한 것 / P04·P06 남은 한계 / P09 면책 / P10 PROBLEM).
4. **제어권 박탈은 최대 2회**, 각각 예고 + 건너뛰기 + 세션당 1회 + Esc + 언마운트 정리 + reduced-motion 비활성.
5. **자동 애니메이션은 뷰포트 밖 + 탭 숨김 시 정지.**
6. **스크롤 위치를 React state로 관리 금지** → CSS 변수 + `requestAnimationFrame`.
7. **코드 패널을 프레임/단계마다 리렌더 금지** → ref + class 토글.
8. **숫자는 전부 `tabular-nums`.**
9. `prefers-reduced-motion` 대응을 모든 페이지에 명시.
10. **`aria-live` 남용 금지** (실시간 로그/피드는 `aria-hidden` + 숨김 요약문).
