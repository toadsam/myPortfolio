# 04. 득근득근 (MuscleUp) — 「캐릭터 성장 시트」

> 운동 기록 게임화 + 커뮤니티 풀스택 · TypeScript / React / Spring Boot / JWT / OAuth / Socket.IO
> 테마: `primary #f472b6` / `secondary #ec4899` / `bg #140510` / `accent #f9a8d4`

## 0. 한 줄 컨셉

**"관람객이 이 페이지를 읽는 동안 레벨이 오른다."**

이 프로젝트의 핵심 아이디어는 "운동 기록 → 즉시 보상 → 지속"이다.
그러면 화면도 똑같이 작동해야 한다. **스크롤이 곧 운동이고, 섹션 통과가 곧 EXP다.**

읽기 시작할 때 Lv.1. 다 읽으면 Lv.5.
왼쪽 상단에 캐릭터 스탯 창이 계속 떠 있고, 섹션을 지날 때마다 `+120 EXP` 토스트가 뜨고 게이지가 찬다.

**관람객이 게임화의 효과를 설명으로 듣는 게 아니라 직접 당한다.** 그게 전부다.

## 2. 진입 연출 (0 → 2.3초)

**캐릭터 생성 화면.**

```
0.0s  검은 화면
0.3s  중앙에 실루엣이 아래에서 솟아오름 (덤벨 아이콘 또는 캐릭터 픽토그램)
0.6s  스탯이 하나씩 롤링되며 확정 (주사위 굴리듯)
        근력   ▓▓▓▓▓▓░░░░  ← 숫자가 랜덤으로 돌다 멈춤
        지구력 ▓▓▓▓░░░░░░
        꾸준함 ▓▓░░░░░░░░   ← 이 항목만 낮게 멈춤
1.4s  "꾸준함" 게이지 위에 빨간 밑줄 + 텍스트
        ⚠ 꾸준함 — 가장 어려운 스탯
1.8s  타이틀
        득근득근
        기록은 쉽다. 계속하는 게 어렵다.
2.3s  스탯 패널이 좌상단으로 축소 이동하며 sticky HUD가 됨
      → 이 순간부터 관람객은 Lv.1
```

- 1.4s의 "꾸준함이 낮다"가 곧 이 프로젝트의 문제 정의다. **연출과 서사가 같은 것**이어야 한다.
- **스킵**: 클릭/키/스크롤 → 2.3s 상태로
- `reduced-motion` → 롤링 없이 즉시 확정값

## 3. 섹션 구성

**레이아웃 대원칙**: 세로 스크롤. 좌상단에 **캐릭터 HUD가 고정(fixed)** 되어 계속 따라온다.
섹션은 "레벨 구간"이다. 각 섹션 헤더에 `LV.2` 같은 배지가 붙는다.

```
┌───────────────────────────────────────────────────────────────┐
│ ← 마을로   득근득근                        🔊  [읽기 모드]     │
├───────────────────────────────────────────────────────────────┤
│ ┌──────────────────┐                                          │
│ │ ⚔ Lv.2  방문자   │  ← fixed HUD (좌상단, 220×96)            │
│ │ EXP ▓▓▓▓▓▓░░░░   │                                          │
│ │ 240 / 400        │                                          │
│ └──────────────────┘                                          │
│                                                               │
│                    ┌─────────────────────┐                    │
│                    │  LV.2               │                    │
│                    │  기록은 왜 끊기는가  │                    │
│                    └─────────────────────┘                    │
│                                                               │
│         본문은 중앙 정렬 max-w-3xl 단일 컬럼                    │
│         (읽는 흐름을 방해하지 않기 위해)                        │
│                                                               │
│                                       ┌──────────────┐        │
│                                       │ +120 EXP  ✦  │ ← 토스트│
│                                       └──────────────┘        │
└───────────────────────────────────────────────────────────────┘
```

> **중요**: 본문은 오히려 **단순한 단일 컬럼**으로 간다.
> 화려한 건 HUD와 토스트와 레벨업 연출이 다 하고 있다. 본문까지 복잡하면 읽을 수 없다.
> (FestFlow처럼 좌우 분할하면 HUD와 충돌한다)

### LV.2 — 기록은 왜 끊기는가 — 문제

**[COPY-03]**
> 운동 기록 앱을 세 번 깔았고 세 번 다 3주를 못 넘겼다.
> 기록하는 건 30초면 되는데, **그 30초를 쓸 이유가 사라지는 게 문제였다.**
> 오늘 기록해도 화면은 어제와 똑같았다. 아무 일도 일어나지 않았다.

**[COPY-04]** (강조 블록)
> 기록이 즉시 보상과 반응으로 이어지면 지속성이 올라간다 — 이게 가설이었다.
> 보상은 캐릭터 성장으로, 반응은 커뮤니티와 실시간 챌린지로 설계했다.

**[NEW]** `RetentionCurveDemo`
```
┌────────────────────────────────────────────────┐
│  ▸ 기록 앱을 쓰는 사람의 3주                    │
│                                                │
│  사용                                          │
│  률  ●─●─●                                     │
│      │     ╲●─●                                │
│      │         ╲●──●──●                        │
│      └───────────────────────▶ 1주  2주  3주   │
│                                                │
```

> ⚠️ 이 그래프는 **가설을 설명하는 개념도**다. 실측 데이터가 아니므로 그래프 하단에 `// 실측이 아닌 설계 가설의 도식` 캡션 **필수**.

## 4. 시그니처 인터랙션 — 「스크롤 = 성장」

**[NEW]** `GrowthHud` + `ExpToast` + `LevelUpFlash`

### GrowthHud (fixed, 좌상단)
```
┌────────────────────────┐
│ ⚔ Lv.2   방문자        │
│ ▓▓▓▓▓▓░░░░  240/400    │
└────────────────────────┘
```
- 화면 좌상단 고정. 모바일에서는 **상단 전체폭 바(높이 44px)** 로 전환
- 게이지는 스크롤 진행률에 연동되지만 **연속이 아니라 계단식** — 섹션을 통과할 때만 확 오른다
  (연속이면 그냥 진행바로 보인다. 계단이어야 "획득"으로 읽힌다)

### ExpToast
- 섹션 하나를 완전히 통과할 때마다 우하단에 토스트
- `+120 EXP  ✦` — 1.6초 후 자동 소멸, 위로 뜨면서 페이드
- 각 섹션마다 EXP량이 다름: LV.1 통과 = +100, LV.2 = +120, LV.3 = +180 (가장 긴 섹션), LV.4 = +150, LV.5 = 도달
- **이미 획득한 섹션은 다시 스크롤해도 재획득 안 됨** (`Set<sectionId>` 로 기록) — 안 그러면 위아래 흔들 때마다 토스트 폭탄

### LevelUpFlash
- 게이지가 가득 차는 순간:
  1. 화면 전체 흰색 플래시 (`opacity 0 → 0.35 → 0`, 0.25s)
  2. 중앙에 `LEVEL UP!  Lv.2 → Lv.3` 0.9초 표시 후 소멸
  3. HUD 게이지가 리셋되며 레벨 숫자 교체 (숫자는 위로 밀려 올라가는 롤 애니메이션)
  4. 사운드 ON이면 팡파레
  5. 파티클 12개가 HUD에서 방사형으로 튀어나감
- **레벨업은 총 4회.** 그 이상 남발하면 싸구려가 된다.

### 접근성 / 탈출구
- `[읽기 모드]` 토글 → HUD·토스트·플래시 전부 끄고 단순 문서로. **필수.**
- `prefers-reduced-motion` → 플래시와 파티클 생략, 게이지는 즉시 이동, 토스트는 페이드만
