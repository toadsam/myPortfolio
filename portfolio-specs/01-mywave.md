# 01. MyWave — 「돈의 흐름을 물결로」

> 개인 자산 흐름 금융 대시보드 · React / TypeScript / Chart UI / Tailwind
> 테마: `primary #34d399` / `secondary #10b981` / `bg #04110c` / `accent #6ee7b7`

---

## 0. 한 줄 컨셉

**"통장을 보는 게 아니라, 물길을 따라 내려간다."**

방에 들어오면 어두운 수면 위에 잔물결만 있다.
스크롤을 내리는 행위가 곧 **시간이 흐르는 것**이고, 그에 따라 자산 곡선이 왼쪽에서 오른쪽으로 그려진다.
숫자를 나열하는 대시보드가 아니라, **흐름을 몸으로 느끼게 하는 화면**.

이 프로젝트를 뽑은 이유: 배운 점이 "정보 설계"였다. 그러니 화면 자체가 정보 설계의 증거여야 한다.

## 2. 진입 연출 (0 → 2.4초)

```
0.0s  검은 화면. 화면 하단 30%에만 아주 희미한 수평선.
0.3s  수평선에서 파문 1개가 좌우로 퍼짐 (scaleX 0 → 1, opacity 1 → 0)
      + 물방울 사운드 1회
0.6s  "MyWave" 글자가 수면 아래에서 위로 떠오름 (y: 24 → 0, blur 8px → 0)
1.0s  태그라인 페이드인 (아래 [COPY-01])
1.4s  화면 전체가 위로 살짝 밀리며 첫 섹션 진입
      동시에 자산 곡선의 첫 픽셀이 좌측 끝에 찍힘
2.4s  스크롤 힌트 ↓ 가 3회 부드럽게 위아래 (그 후 사라짐)
```

- **스킵**: 아무 키/클릭/스크롤 → 즉시 1.4s 상태로 점프
- `prefers-reduced-motion` → 파문·부상 생략, 페이드인만 0.3s

## 3. 섹션 구성

**레이아웃 대원칙**: 전체가 하나의 연속된 세로 스크롤.
좌측 40%는 `position: sticky` 로 **자산 곡선이 계속 붙어 있고**, 우측 60%의 텍스트가 흘러간다.
스크롤 진행률(0~1)이 곡선의 그려짐 정도와 좌측 숫자에 실시간으로 연동된다. ← **이게 이 프로젝트의 전부다.**

```
┌──────────────────────────────────────────────────────────────┐
│  ← 마을로   MyWave                          🔊  [읽기 모드]   │  상시 고정 헤더 (h 56px)
├───────────────────────────┬──────────────────────────────────┤
│                           │                                  │
│   [ sticky 좌측 패널 ]     │   [ 흐르는 우측 본문 ]            │
│                           │                                  │
│   총자산   ₩ 12,480,000   │   S1. 왜 만들었나                 │
│   ▁▂▃▅▆▇█  (곡선)         │   S2. 무엇이 문제였나             │
│   ────────────────        │   S3. 정보 설계                   │
│   이번 달 흐름  +8.2%      │   S4. 만든 것                    │
│                           │   S5. 남은 것                     │
│   ● 목표까지 62%           │                                  │
│                           │                                  │
└───────────────────────────┴──────────────────────────────────┘
        40%                              60%
```

> 좌측 숫자는 **더미 데이터**임을 반드시 명시한다. 곡선 하단에 `// 데모용 샘플 데이터` 캡션 상시 표기.
> 실제 금융 데이터인 척하면 그게 제일 위험하다.

## 4. 시그니처 인터랙션 — 「타임 스크럽 곡선」

**[NEW]** `WaveScrubChart`

좌측 sticky 패널의 자산 곡선이 **스크롤 진행률에 완전히 종속**된다.

```
scrollProgress 0.0 ──────────────────────── 1.0
곡선 그려짐    0%                          100%
총자산 숫자    ₩0        (CountUp 아님, 스크럽)    ₩12,480,000
곡선 끝점      ●  ← 항상 최신 지점에서 맥동(pulse)
```

동작 명세:
1. `useScroll()` 로 컨테이너 진행률 취득 → `useSpring` 으로 부드럽게 감쇠 (stiffness 90, damping 30)
2. SVG `<polyline>` 의 `strokeDasharray` / `strokeDashoffset` 으로 그려짐 제어
3. 곡선 아래 area는 `clipPath` 로 같은 진행률만큼만 채움
4. 총자산 숫자는 진행률 × 최종값 — **되감으면 숫자도 내려간다** (CountUp과 다른 점, 이게 재미)
5. 끝점 `●` 는 항상 그려진 마지막 좌표에 붙어서 `boxShadow` 맥동
6. S1(문제) 구간에서만 `filter: saturate(0.15)` 적용 → 탈색

성능:
- 곡선 포인트는 **최대 60개**. 그 이상은 눈에 안 보이고 프레임만 먹는다.
- `will-change: transform` 은 sticky 패널에만.
- 뷰포트 이탈 시 스프링 애니메이션 중단.

모바일 (`< 1024px`):
- sticky 좌우 분할 해제 → 곡선을 **화면 상단 고정 밴드(높이 120px)** 로 축소해서 붙임
- 총자산 숫자는 밴드 안 좌측, 곡선은 우측
- 스크럽 동작은 그대로 유지
